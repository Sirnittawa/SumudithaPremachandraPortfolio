# Portfolio starter site

Static HTML/CSS, no build step. Colours, type and grid come from the Design System Manual (`styles.css` holds the tokens).

## Files
- `index.html` — home page
- `adaraya/index.html` — project page
- `styles.css` — tokens plus site styles
- `assets/` — put your images here (reference them as `assets/name.jpg`, or `../assets/name.jpg` from the project page)

## Publish on GitHub Pages
1. On github.com click **New repository**. Name it e.g. `portfolio`. Set it to Public. Create it.
2. Click **uploading an existing file**. Drag in the *contents* of this folder (index.html, styles.css, adaraya/, assets/), keeping the folder structure. Click **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. After 1–2 minutes the site is at `https://YOUR-USERNAME.github.io/portfolio/`.

## Fill in
Search for `[` in both HTML files. Every `[CONFIRM]` or `[YOUR NAME]` is a placeholder. Don't state a project's status until you've confirmed it. The pavilion is marked **Not built** and the reconstruction section is labelled as retrospective.

## Preview locally
Open `index.html` in a browser. Fonts need internet.
